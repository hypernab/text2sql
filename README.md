# Text2SQL 
Translate natural language into executable SQL queries in real-time.
[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_svg)](https://text2sql-prabhnoor.streamlit.app/)
[![Python](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)

## ✨ What it does
- **Ask in English:** Type a normal question, get a data answer.
- **Smart Filtering:** It knows the difference between a real question and just saying "hi."
- **Live Data:** You can add or delete students in the "Database Control" tab to test it out.
- **Clean UI:** Built with Streamlit.
