# Text2SQL
**Translate natural language into executable SQL queries in real-time.**
<img src="https://streamlit.io/images/brand/streamlit-logo-secondary-colormark-darktext.png" width="200">
![Python 3.13+](https://img.shields.io/badge/python-3.13+-blue.svg)

### ✨ What it does
* **Ask in English:** Type a normal question, get a data answer instantly.
* **Smart Filtering:** Custom guardrails to ignore "hi," "hello," or gibberish.
* **Live Data:** Use the **Database Control** tab to add or delete records and watch the AI adapt.
* **Clean UI:** A fully interactive web interface built with Streamlit.
